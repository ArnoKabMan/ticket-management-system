# ticket-management-system

A system that will connect users with their support agents and aid in live communication of the two parties. The backend system will manage operational incidents, approvals, and workflows in enterprise environments.

## Tech Stack
- Java 25+
- Spring Boot
- PostgreSQL
- Spring Security (JWT)
- Docker (planned)

## Features (WIP)
- User authentication
- Ticket creation
- Approval workflows
- Assignment system
- Audit logging
- Notifications

## Architecture
Monolithic Spring Boot service with layered architecture:
- Controller
- Service
- Repository
- Entity
- DTO
